# Pixar-Movie-Success-Dashboard
1. An interactive Power BI dashboard designed to analyze Pixar movies through financial performance, audience reception, and creative factors.

2. Short Description

The Pixar Movie Success Dashboard provides a consolidated view of movie performance across multiple dimensions. The report is organized into four analytical sections—Overview, Financial Success, Audience Insights, and Creative Drivers—allowing users to explore trends, compare movie performance, and understand the factors that contribute to Pixar's success.

3. Tech Stack

## Tools & Technologies

* Power BI Desktop
* Power Query
* DAX
* Data Modeling
* Data Visualization
* Microsoft Excel / CSV Dataset

Key Power BI Skills Demonstrated:

* Data Cleaning
* Data Transformation
* Data Modeling
* DAX Measures
* Interactive Dashboard Design
* KPI Development
* Storytelling with Data

4. Data Source : Maven  

5. ## Key Insights

* Pixar maintains consistently strong audience ratings across its film portfolio.
* Higher budgets do not always guarantee higher returns.
* Certain directors contribute significantly more revenue than others.
* A small number of blockbuster films generate a large share of total revenue.
* Audience and critic scores generally show positive alignment.
* Specific genres contribute disproportionately to Pixar's overall box office success.
